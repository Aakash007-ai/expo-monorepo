# Architecture Decision Records

Every decision that settles a grilling question gets recorded here as an ADR.
Each ADR is one file (`NNNN-title.md`), immutable once accepted — a later
change is a new ADR that supersedes it.

## How to write an ADR

- **Context:** the problem/tension that forced the decision
- **Decision:** what we decided, in one clear statement
- **Consequences:** what this makes easier and harder
- **Alternatives rejected:** the options we didn't take and why
